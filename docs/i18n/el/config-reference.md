# Οδηγός Ρυθμίσεων LlamaFarm (config.toml)

Αυτός ο οδηγός εξηγεί τις πιο σημαντικές ρυθμίσεις που μπορείτε να κάνετε στο αρχείο `config.toml`.

Τελευταίος έλεγχος: **30 Ιουλίου 2026**.

## Πού βρίσκεται το αρχείο ρυθμίσεων

Το LlamaFarm ψάχνει για τις ρυθμίσεις με την εξής σειρά:
1. Στη διαδρομή που ορίζει η μεταβλητή `LLAMAFARM_WORKSPACE`.
2. Στο αρχείο `~/.llamafarm/config.toml` (αυτή είναι η συνηθισμένη θέση).

## Βασικές Ρυθμίσεις (Core)

| Ρύθμιση | Τι ορίζει |
|---|---|
| `default_provider` | Ποιον πάροχο AI χρησιμοποιείτε (π.χ. `openai`, `ollama`). |
| `default_model` | Ποιο συγκεκριμένο μοντέλο AI χρησιμοποιείτε (π.χ. `gpt-4o`). |
| `default_temperature` | Πόσο "δημιουργική" θα είναι η AI (τιμή από 0 έως 2). |

## 1. Συμπεριφορά της AI (Agent)

- `max_tool_iterations`: Αριθμός χρήσεων εργαλείων ανά μήνυμα (προεπιλογή: `0`, χωρίς όριο). Η εκτέλεση συνεχίζεται μέχρι ολοκλήρωση, πραγματική αδράνεια/σφάλμα ή ρητή ακύρωση από τον χειριστή. Μια θετική τιμή ορίζει ρητό όριο ανά γύρο.
- `research.max_iterations`: Αριθμός γύρων έρευνας (προεπιλογή: `0`, χωρίς όριο). Η παραγωγική έρευνα συνεχίζεται μέχρι ολοκλήρωση, σφάλμα provider/tool ή ανίχνευση πανομοιότυπων κλήσεων/αποτελεσμάτων. Μια θετική τιμή ορίζει ρητό όριο έρευνας.
- `host_runner.max_exec_timeout_secs`: Μέγιστη θετική προθεσμία foreground εκτέλεσης (προεπιλογή: `0`, χωρίς μέγιστο). Παράλειψη ή μηδενικό `timeout_secs` δεν επιβάλλει χρονική προθεσμία· μια θετική τιμή ορίζει ρητή προθεσμία.
- `max_history_messages`: Πόσα προηγούμενα μηνύματα θυμάται η AI στη συνομιλία (προεπιλογή: 50). Η τιμή `0` διατηρεί όλο το ακατέργαστο ιστορικό μέχρι η πραγματική πίεση παραθύρου του παρόχου να απαιτήσει συμπύκνωση.
- `max_output_tokens_per_turn`: Προϋπολογισμός token ανά τμήμα συλλογισμού/εξόδου (προεπιλογή: `16384`). Όταν εξαντληθεί, η ίδια εργασία συνεχίζεται από checkpoint.
- `max_no_progress_spins`: Διαδοχικά κενά τμήματα συλλογισμού ή διπλότυπες επαναλήψεις εργαλείων πριν από έξοδο λόγω αδράνειας (προεπιλογή: `6`). Η πραγματική πρόοδος μηδενίζει αμέσως τον μετρητή.
- `tool_routing_enabled`: Ενεργοποιεί την επιλογή εργαλείων ανά γύρο στο WebSocket Agent Chat (προεπιλογή: `true`). Σε αίτημα χωρίς επαρκές σήμα ή χωρίς αντιστοίχιση διατηρεί όλα τα εργαλεία που επιτρέπει η πολιτική.
- `tool_routing_top_k`: Μέγιστος αριθμός σχετικών μη βασικών εργαλείων πριν προστεθούν τα βασικά εργαλεία και οι απαιτούμενες εξαρτήσεις (προεπιλογή: `12`, τιμή `0` απενεργοποιεί τη δρομολόγηση).
- `scheduler.max_concurrent`: Μέγιστος συνολικός αριθμός προγραμματισμένων εργασιών που εκτελούνται ταυτόχρονα (προεπιλογή: `4`). Η τιμή `0` καταργεί το όριο ταυτόχρονης εκτέλεσης· η μεταβλητή `LLAMAFARM_SCHEDULER_MAX_CONCURRENT` το παρακάμπτει.

Οι αποφάσεις δρομολόγησης εμφανίζονται στο Run Inspector. Για άμεσο rollback
χρησιμοποιήστε `LLAMAFARM_AGENT_TOOL_ROUTING_ENABLED=0` ή
`LLAMAFARM_AGENT_TOOL_ROUTING_TOP_K=0`.

Το `gateway.require_pairing` είναι πεδίο παλαιάς συμβατότητας με προεπιλογή
`false`. Το pairing έχει αποσυρθεί και η τιμή αγνοείται κατά την εκτέλεση.

Το `provider.ollama_workers` ορίζει διεργασίες Ollama δεσμευμένες σε μία GPU ή
σε σύνολο GPU και το `provider.ollama_model_placements` δρομολογεί μοντέλα σε
αυτές. Με `spread = true` ένα μοντέλο μοιράζεται στο σύνολο GPU, ενώ ξεχωριστοί
workers μπορούν να κρατούν διαφορετικά μοντέλα ταυτόχρονα στη μνήμη.

Αν μια δεξιότητα δεν δηλώνει δομημένα τις εξαρτήσεις εργαλείων της (ιδίως ένα
αυτόνομο `SKILL.md`), η δρομολόγηση διατηρεί ολόκληρο το registry ώστε η
δεξιότητα να μη χάσει εργαλεία όταν φορτωθεί κατ’ απαίτηση.

## 2. Αυτονομία και Ασφάλεια (Autonomy)

Εδώ ρυθμίζετε πόση ελευθερία έχει η AI να κάνει αλλαγές στον υπολογιστή σας.

- `level`:
    - `read_only`: Μπορεί μόνο να διαβάζει αρχεία.
    - `supervised`: Χρειάζεται την έγκρισή σας για σημαντικές ενέργειες (προεπιλογή).
    - `full`: Μπορεί να τρέχει εντολές ελεύθερα (προσοχή!).
- `allowed_commands`: Λίστα με τις εντολές που επιτρέπεται να τρέχει η AI.
- `forbidden_paths`: Φάκελοι που η AI **δεν** επιτρέπεται να αγγίξει (π.χ. `/etc`).

Τοπικό πρότυπο προφίλ:

- `dev/config.template.toml`: το μοναδικό ισχυρό τοπικό προφίλ operator με ευρεία πρόσβαση σε userland, Docker, web, memory και delegation, αλλά με σκληρό μπλοκάρισμα για kernel, drivers, firmware, initramfs, bootloader και καταστροφικές ενέργειες δίσκου.

## 3. Μνήμη (Memory)

Πώς αποθηκεύει η AI τις πληροφορίες που της δίνετε.
- `backend`: Μπορεί να είναι `sqlite` (βάση δεδομένων), `markdown` (απλά αρχεία κειμένου) ή `none` (καμία μνήμη).

## 4. Κανάλια Επικοινωνίας (Channels)

Κάθε κανάλι (Telegram, Discord κ.λπ.) έχει τη δική του ενότητα στο αρχείο.

Παράδειγμα για το **Telegram**:
```toml
[channels_config.telegram]
bot_token = "το-κλειδί-σας"
allowed_users = ["το-όνομά-σας"] # Ποιοι επιτρέπεται να μιλάνε στο bot
```

## 5. Έλεγχος Κόστους (Cost)

Αν χρησιμοποιείτε πληρωμένες υπηρεσίες AI, μπορείτε να βάλετε όρια.
- `daily_limit_usd`: Μέγιστο ποσό ανά ημέρα (π.χ. 10.00 δολάρια).
- `monthly_limit_usd`: Μέγιστο ποσό ανά μήνα.

## 6. Εικόνες (Multimodal)

Ρυθμίσεις για το πώς η AI βλέπει εικόνες.
- `max_images`: Μέγιστος αριθμός εικόνων ανά μήνυμα.
- `allow_remote_fetch`: Αν επιτρέπεται στην AI να κατεβάζει εικόνες από το ίντερνετ μέσω συνδέσμων (links).

## Συνδέσεις βάσεων δεδομένων (`[[db_connections]]`)

Οι επώνυμες συνδέσεις χρησιμοποιούνται από το Database Explorer και τα εργαλεία
`db_schema`/`db_query`. Υποστηρίζονται οι drivers `sqlite`, `postgres`, `mysql`
(και MariaDB) και `mongodb`. Το MySQL/MariaDB απαιτεί το Cargo feature
`db-mysql`, το οποίο είναι ενεργό από προεπιλογή στο bundled Docker image.

---

## Συμβουλές

- Αν αλλάξετε το αρχείο `config.toml`, πρέπει να κάνετε επανεκκίνηση το LlamaFarm για να δει τις αλλαγές.
- Χρησιμοποιήστε την εντολή `llamafarm doctor` για να βεβαιωθείτε ότι οι ρυθμίσεις σας είναι σωστές.
- Μην μοιράζεστε ποτέ το αρχείο `config.toml` με άλλους, καθώς περιέχει τα μυστικά κλειδιά σας (tokens).

## Ενημέρωση

- Προστέθηκε το `model_routes[].api_url`, ώστε κάθε route να μπορεί να παρακάμπτει το γενικό `api_url`.
- Είναι χρήσιμο όταν διαφορετικά hints πρέπει να στοχεύουν σε διαφορετικά τοπικά inference endpoints του ίδιου τύπου provider.
- Το `provider.ollama_num_ctx` είναι ακριβής χειροκίνητη τιμή context· το
  dashboard δέχεται 2.048–262.144 tokens. Όταν δεν ορίζεται, το
  Auto χρησιμοποιεί το εγγενές μέγιστο του μοντέλου.
- Με `LLAMAFARM_ADAPTIVE_CONTEXT=true`, το `OLLAMA_NUM_CTX` γίνεται η γρήγορη
  βάση. Το LlamaFarm αυξάνει το παράθυρο σε βαθμίδες ×2 όταν το χρειάζεται το
  αίτημα, έως το μικρότερο από το εγγενές context του μοντέλου και το
  `LLAMAFARM_ADAPTIVE_CONTEXT_MAX` (προεπιλογή 262.144).
