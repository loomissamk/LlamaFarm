# Справочник провайдеров (Русский)

Это первичная локализация Wave 1 для проверки provider ID, алиасов и переменных окружения.

Оригинал на английском:

- [../../providers-reference.md](../../providers-reference.md)

## Когда использовать

- Выбор провайдера и модели
- Проверка ID/alias/credential env vars
- Диагностика ошибок аутентификации и конфигурации

## Правило

- Provider ID и имена env переменных не переводятся.
- Нормативное описание поведения — в английском оригинале.

## Адаптивный контекст Ollama

- `provider.ollama_num_ctx` задаёт точное ручное переопределение.
- Если оно не задано, `OLLAMA_NUM_CTX` служит значением окружения по умолчанию;
  при `LLAMAFARM_ADAPTIVE_CONTEXT=true` это быстрый базовый уровень.
- Профиль RTX 5070 Ti начинает с 65 536 и выбирает 131 072 или 262 144 только
  когда этого требует оценка запроса. Рост ограничен меньшим из нативной длины
  модели и `LLAMAFARM_ADAPTIVE_CONTEXT_MAX`.
- Фактически выделенный Ollama контекст проверяется командой
  `docker exec LlamaFarm ollama ps`.
