# Справочник конфигурации (Русский)

Это первичная локализация Wave 1 для работы с ключами конфигурации и безопасными дефолтами.

Оригинал на английском:

- [../../config-reference.md](../../config-reference.md)

## Когда использовать

- Первичная настройка окружения
- Проверка конфликтов конфигурации
- Аудит параметров, влияющих на безопасность и стабильность

## Правило

- Названия config keys не переводятся.
- Точное runtime-поведение определяется английским оригиналом.

## Обновления

- Значение по умолчанию `agent.max_tool_iterations` теперь равно `0` (без лимита): выполнение продолжается до завершения, реальной остановки/ошибки или явной отмены оператором. Положительное число по-прежнему задаёт явный лимит на ход.
- Значение по умолчанию `research.max_iterations` также равно `0` (без лимита): продуктивное исследование продолжается до завершения, ошибки provider/tool или срабатывания детектора одинаковых вызовов/результатов. Положительное число задаёт явный лимит исследования.
- `gateway.require_pairing` — устаревшее поле совместимости со значением по умолчанию `false`; pairing выведен из эксплуатации, и runtime игнорирует это значение.
- Добавлен `model_routes[].api_url`, который переопределяет верхнеуровневый `api_url` только для конкретного route.
- Это полезно, когда разные hints должны указывать на разные локальные inference endpoints одного и того же типа provider.
- `provider.ollama_num_ctx` задаёт точное ручное окно контекста; панель принимает
  2 048–262 144. Если поле не задано, runtime использует `OLLAMA_NUM_CTX`.
- При `LLAMAFARM_ADAPTIVE_CONTEXT=true` значение окружения становится быстрым
  базовым уровнем. LlamaFarm увеличивает окно ступенями ×2 по потребности запроса
  до меньшего из нативного окна модели и `LLAMAFARM_ADAPTIVE_CONTEXT_MAX`
  (по умолчанию 262 144).
